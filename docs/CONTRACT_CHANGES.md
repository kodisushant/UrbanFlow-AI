# UrbanFlow AI — Traffic Intelligence Data Contract Changes (Member 3)

This document details all schema and semantic contract changes made to the Traffic Intelligence API since the initial kickoff version.

**Target Audience:** Member 1 (Backend Coordinator), Member 2 (Computer Vision / CCTV), Member 4 (Route Optimization).

---

## 1. Summary of Changes

| Field / Location | Change Type | Description / Rationale |
|---|---|---|
| `forecast.horizon_*.heuristic_confidence` | **Breaking Rename** | Renamed from `confidence` to `heuristic_confidence`. Reflects that this is a volatility-derived heuristic $[0.0, 1.0]$, **not** a calibrated statistical probability. |
| `timestamp` (all levels) | **Format Change** | Datetimes now include the ISO 8601 timezone offset (configured default: `+05:30` / `Asia/Kolkata`), replacing offset-naive strings. Aware inputs with `"Z"` are automatically normalized. |
| `intersection_id` | **New Optional Field** | Added at top level and inside `current_state` (default `null`). Allows intersection-level telemetry; pipeline isolates temporal lag history by `(road_id, intersection_id)`. |
| `forecast_reliability` | **New Field** | Added at top level and inside `data_provenance`. Tri-state string indicator: `"normal"`, `"low_during_incident"`, or `"low_cold_start"`. |
| `data_provenance.training_data` | **New Provenance Key** | Discloses training data source (`"synthetic"`). |
| `data_provenance.forecast_type` | **New Provenance Key** | Indicates engine mode: `"model_prediction"` or `"rule_based_fallback"`. |
| `data_provenance.forecast_reliability` | **New Provenance Key** | Mirrors top-level `forecast_reliability`. |

---

## 2. Field-by-Field Rules and Values

### 1. `forecast_reliability` (Top-level & Provenance)
- **`"normal"`**: Generated by the trained ML model when `current_state.is_abnormal == False`.
- **`"low_during_incident"`**: Triggered when `current_state.is_abnormal == True`. Alerts downstream agents (Member 1 & 4) that the ML model has little incident training data to extrapolate from and may lag severe shockwaves.
- **`"low_cold_start"`**: Generated when history has fewer than 4 bucketed observations ($< 20$ minutes) or after a data gap $> 15$ minutes, indicating rule-based exponential smoothing extrapolation.

### 2. `heuristic_confidence` (Inside each forecast horizon)
- Value range: $[0.0, 1.0]$.
- Heuristic calculation: $C_{15} = \max(0.60, \min(0.92, 0.90 - 0.5 \cdot \sigma))$, where $\sigma$ is recent 15-minute congestion volatility. In cold-start mode, fixed at $0.65$ (15m) and $0.55$ (30m).

### 3. `intersection_id` (Optional)
- String identifier (e.g. `"INT-05"`).
- If omitted or `null`, observation is treated as road-segment level.

### 4. `timestamp`
- String formatted in ISO 8601 with explicit offset: `YYYY-MM-DDTHH:MM:SS+05:30`.
